plotXVG manual
==============

plotXVG makes publication-quality graphs with Matplotlib from xvg files, as
written by GROMACS and the `Alexandria Chemistry Toolkit
<https://github.com/AlexandriaChemistry/ACT>`_ (ACT), and from csv and dat
files. It works from the command line and from Python.

This manual describes plotXVG version |release|: how to install it, how to
use it, all its options, and many example plots.
