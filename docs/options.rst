Options
=======

These are all options of the command ``plotxvg``. The same descriptions are
shown by ``plotxvg -h``. In Python, the options are keyword arguments of
``plotxvg.plot()`` with the long name of the option, for instance
``linestyle``.

   :module: plotxvg.plotxvg
   :func: build_parser
   :prog: plotxvg
